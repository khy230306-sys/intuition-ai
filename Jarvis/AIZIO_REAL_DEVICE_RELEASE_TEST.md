## 사용자가 직접 해야 하는 항목

- API 키 입력 (OpenAI / OpenRouter)
- 마이크·카메라·알림·위치 권한 허용
- Push 서버 URL 연결 (종료 상태 개인 알림용)
- iPhone: Safari 공유 → 홈 화면에 추가
- Android: Chrome 설치 배너 / 홈 화면 추가
- Apple/Google 계정·결제·운영 서버 권한 (해당 시)

- 출시 준비 검사 **FAIL 0**
