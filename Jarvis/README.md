# JARVIS — iPhone 만능·투자 AI 비서

iPhone Safari에서 앱처럼 쓰는 개인 AI 비서 PWA입니다.  
**실생활 비서 + 주식 투자 도구**를 한곳에서 사용합니다.

## 바로 사용 (iPhone)

**앱 URL:** https://laced-tracer-uv22sxn.shipstatic.com

> 게이트/번역 바에 **v1.5.5**이 보여야 최신입니다.  
> 앱 실행 시 **위치 허용이 필수**입니다. (홈 화면 추가 순간에는 iOS가 위치 창을 띄울 수 없어, 첫 실행 때 막습니다.)

1. iPhone **Safari**로 위 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 **JARVIS** 아이콘으로 실행

> ShipStatic 무료 배포는 만료될 수 있습니다. 만료 전 claim 하거나 `npm run deploy:web`으로 다시 배포하세요.

## 투자 기능

- **실시간 시세** — 삼성전자, 엔비디아, AAPL 등 (Yahoo Finance)
- **관심종목 / 포트폴리오** — 평단·손익 추적
- **매매노트** — 매수 아이디어·논리 기록
- **포지션 사이징** — 자본·리스크%·진입·손절
- **적립식·복리 계산**
- **장 시간** — 한국/미국 개장·장전·장후 + 남은 시간
- **환율** — 달러·엔·유로·위안·파운드 (실시간, 실패 시 오프라인 가정환율)
- **투자 체크리스트** · 성향별 가이드
- 네이버 금융 / TradingView / 뉴스 바로가기

### 투자 명령 예

- `주식 종목 추천` / `냉정하게 추천` / `미국 보수 추천`
- `삼성전자 시세` / `엔비디아 주가`
- `관심종목 애플 추가`
- `보유 삼성전자 10주 평단 70000`
- `포트폴리오`
- `포지션 자본 1000만 리스크 1% 진입 70000 손절 65000`
- `적립식 매달 50만 10년 연7%`
- `삼성전자 투자체크` / `장시간` / `장 열렸어`
- `100달러 환율` / `엔화 10000엔` / `환율`

면책: 투자 조언이 아니며, 시세·환율은 지연·오차 가능. 결정은 본인 책임입니다.

## 생활 기능

- **홈 요약 위젯** — 채팅 상단에 날씨 · 할 일 2개 · 오늘 지출 · 다음 알림
- 브리핑, 할 일, 장바구니, **말한마디 지출**(`커피 4500`), 습관, 일기, 기억
- **로컬 알림** — `알림 30분 뒤 약` / `오후 3시에 알려줘 회의` (앱이 열려 있을 때 확실)
- **앱 QR 공유** — `앱 공유` / 홈 위젯 QR / 설정·실행 탭
- **백업 공유보내기** — Web Share로 파일·iCloud·Drive·메일·메모 (설정 → 백업 공유보내기)
- 계산·단위변환·더치페이, 날씨·지도·앱 실행, 음성 입·출력
- 선택적 OpenAI API로 심화 대화
## 세계·지리

한국을 포함한 전 세계 국가·도시 정보:

- `프랑스 정보` / `브라질 수도` / `이집트 인구`
- `도쿄 시차` / `뉴욕 위치` / `파리 지도`
- `에베레스트` / `아마존` / `대륙 목록`

내장 DB(국가·주요 도시) + 위키백과 요약 + 지도/날씨 연결.

## 오프라인 아케이드

데이터·인터넷 없이 플레이. 하단 **게임** 탭 또는 `게임` / `아케이드`.

1. **스네이크** — 방향 버튼으로 조작
2. **벽돌깨기** — 드래그로 패들
3. **스페이스** — 좌우 드래그 · 자동 발사

최고 기록은 이 기기에만 저장됩니다.

## 실시간 통역 (전 세계 언어)

**데이터(인터넷) 없이도** 기본 여행·일상 표현을 오프라인 통역합니다.  
MIC로 말하면 번역 후 해당 언어로 읽어 줍니다. (말씀 끝난 뒤 약 2초 침묵 후 전송)

### 스톱할 때까지 번역 잠금
한 번 켜면 **한국말 → 그 언어만** 번역합니다. 다른 기능은 무시됩니다.

- `지금부터 스톱할 때까지 베트남어로 번역해줘`
- `내 말을 영어로 번역해줘`
- `일본어로만 번역`
- 끝: `스톱` / `그만` / `통역 종료`

한 문장만: `베트남어로 번역해 나는 이미 식사했어요` (이후에도 잠금이 이어집니다)

지원: 한·영·일·중·스·프·독·베트남 등. 온라인 번역 결과는 기기에 저장됩니다.

## 실시간 통계

숫자를 넣으면 JARVIS가 통계를 계산해 해답을 줍니다.

- `데이터 수익률 1.2 -0.5 3.1 0.8`
- `추가 2.0` (실시간 추가)
- `통계` / `평균` / `표준편차` / `승률`
- `확률 0 이상` (정규분포 가정)
- `상관 광고 매출` / `회귀 광고 매출`
- `시세기록 삼성전자` (실시간 시세 → 데이터셋)

생활 탭의 **STATS**에서 데이터셋·요약 리포트도 확인할 수 있습니다.

## 음성

- MIC 버튼 → 실시간 자막 → **말 끝난 뒤 약 2초 침묵 후** 자동 전송 (중간에 끊지 않음)
- Safari가 세션을 끊어도 자동 재시작하며 이어서 듣습니다
- 설정 → **음성 시스템 테스트**로 지원 여부 점검
- `npm test` (유닛) · `npm run test:voice` (Chrome E2E)
