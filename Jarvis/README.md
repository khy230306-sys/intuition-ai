# AIZIO (아이지오) — iPhone 만능·투자 AI 비서

iPhone Safari에서 앱처럼 쓰는 개인 AI 비서 PWA입니다.  
**실생활 비서 + 주식 투자 도구**를 한곳에서 사용합니다.

## 바로 사용 (iPhone)

**앱 URL (고정 — 앞으로도 이것만):** https://jarvis-app.shipstatic.com

> 게이트/번역 바에 **v1.9.16**이 보여야 최신입니다.  
> 홈 화면에 추가한 앱이 예전 버전이면 **업데이트** 버튼을 누르세요.  
> 주소는 반드시 **https://jarvis-app.shipstatic.com** 입니다. 다른 `*.shipstatic.com` 스냅샷 주소는 옛 버전일 수 있습니다.  
> 위치 허용을 권장합니다. 거부해도 **오프라인으로 계속**으로 게임·대화·설정을 쓸 수 있습니다.  
> **주소는 바뀌지 않습니다.** 업데이트해도 항상 위 링크로 접속하세요.
>
> ShipStatic **무료 플랜**은 배포 스냅샷이 약 **10개**까지입니다. `npm run deploy:web`이 업로드 전에 연결되지 않은 옛 스냅샷을 자동 삭제합니다.

1. iPhone **Safari**로 위 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 **AIZIO** 아이콘으로 실행

## 가족 공간

하단 **가족** 탭에서 가족끼리 쓰는 작은 공유 공간입니다.

- **단체 대화** — 가족 채팅
- **공지** — 고정 가능한 가족 공지
- **일정** — 날짜/시간 가족 일정
- **초대 코드** — 6자리 코드로 참여 (`초대 공유`로 전달)
- **한 번 승인 입장** — 상대가 링크를 열고 «승인하고 입장»만 누르면 완료. 초대자도 앱을 열어 두면 멤버·대화 자동 연결
- **실시간 동기화** — 같은 코드로 앱을 연 기기끼리 P2P(WebRTC) 동기화 (서버 계정 불필요)
- **채팅 알림** — 설정에서 가족/친구 대화 알림 켜기. 앱을 쓰지 않을 때 알림은 **홈 화면에 추가**한 AIZIO + 설정 → **알림 권한 · 백그라운드 푸시 켜기** 필요

명령 예: `가족 공간` / `가족 공지` / `가족 일정` / `가족 만들기`

> 모든 가족이 동시에 앱을 열어 두면 메시지가 서로 전달됩니다. 앱을 끄면 그 기기에 저장된 내용만 남고, 다시 만나면 동기화됩니다. 백그라운드 알림은 상대 기기가 푸시를 켠 멤버로 등록되어 있어야 합니다.

## 친구 공간 (NEW)

하단 **친구** 탭 — 가족 공간과 같은 구조의 **친구 전용** 공유 공간입니다. 가족과 코드·데이터가 분리됩니다.

- **단체 대화** · **공지** · **일정**
- **초대 공유** — 링크/QR/`?friends=코드`. 상대는 «승인하고 입장» 한 번이면 끝
- **코드/링크 붙여넣기** · 앱 안 **카메라 QR / 사진 QR**
- P2P 동기화 (양쪽이 앱을 연 상태에서 멤버·메시지 자동 연결)
- 게임 기록 순위는 **게임** 탭에서 공유

명령 예: `친구 공간` / `친구 공지` / `친구 일정` / `친구 만들기`

> 초대자와 친구가 잠시 AIZIO를 함께 열어 두면 멤버가 자동으로 보입니다. «참여 확인» 주고 공유는 오프라인일 때만 필요합니다.

## 투자 기능

- **실시간 시세** — 삼성전자, 엔비디아, AAPL 등 (Yahoo Finance)
- **관심종목 / 포트폴리오** — 평단·손익 추적
- **매매노트** — 매수 아이디어·논리 기록
- **포지션 사이징** — 자본·리스크%·진입·손절
- **적립식·복리 계산**
- **장 시간** — 한국/미국 개장·장전·장후 + 남은 시간
- **환율** — 달러·엔·유로·위안·파운드 (실시간, 실패 시 오프라인 가정환율)
- **투자 체크리스트** · 성향별 가이드
- 네이버 금융 / TradingView / 뉴스 바로가기

### 투자 명령 예

- `주식 종목 추천` / `냉정하게 추천` / `미국 보수 추천`
- `삼성전자 시세` / `엔비디아 주가`
- `관심종목 애플 추가`
- `보유 삼성전자 10주 평단 70000`
- `포트폴리오`
- `포지션 자본 1000만 리스크 1% 진입 70000 손절 65000`
- `적립식 매달 50만 10년 연7%`
- `삼성전자 투자체크` / `장시간` / `장 열렸어`
- `100달러 환율` / `엔화 10000엔` / `환율`

면책: 투자 조언이 아니며, 시세·환율은 지연·오차 가능. 결정은 본인 책임입니다.

## 생활 기능

- **홈 요약 위젯** — 채팅 상단에 날씨 · 할 일 2개 · 오늘 지출 · 다음 알림
- 브리핑, 할 일, 장바구니, **말한마디 지출**(`커피 4500`), 습관, 일기, 기억
- **로컬 알림** — `알림 30분 뒤 약` / `오후 3시에 알려줘 회의` (앱이 열려 있을 때 확실)
- **앱 QR 공유** — `앱 공유` / 홈 위젯 QR / 설정·실행 탭
- **백업 공유보내기** — Web Share로 파일·iCloud·Drive·메일·메모 (설정 → 백업 공유보내기)
- 계산·단위변환·더치페이, 날씨·지도·앱 실행, 음성 입·출력
- 선택적 OpenAI API로 심화 대화

## 오프라인 아케이드

데이터·인터넷 없이 플레이. 하단 **게임** 탭 또는 `게임` / `아케이드`.  
한 단계씩 **레벨업**하며 난이도가 올라갑니다. 최고 점수·최고 레벨은 이 기기에만 저장됩니다.

1. **스페이스** — 초록 M / 금색 W(Lv20+) 미사일 진화 · Lv21부터 속도 완화
2. **플래피** — 기둥 5개마다 레벨업 · 간격 축소
3. **닷지** — 8개 회피마다 레벨업 · 낙하 가속
4. **퐁** — 5회 받아칠 때마다 레벨업 · 공 가속
5. **벽돌깨기** — 스테이지를 깨면 다음 레벨 · 벽돌·속도 증가
6. **스윽** — 슬라이딩 퍼즐 · 시간 안에 숫자 맞추기 · 클리어마다 레벨업
7. **격파** — 첫 버전 세로 슈팅 · 웨이브·보스 · 무기 강화(펄스→트윈→스프레드→레이저) · 라이프·실드·폭탄

홈 화면에 추가한 앱에서 게임이 안 바뀌면 **설정 → 앱 캐시 새로고침** 또는 게임 화면 하단 **앱 새로고침**을 누르세요.

### 친구 순위
닉네임을 정한 뒤 **내 기록 공유**(QR·공유·코드 복사) → 친구가 **친구 기록 받기**에 붙여넣으면 기기 안에서 순위가 쌓입니다.  
서버 계정 없이 로컬에만 저장됩니다. 명령: `게임 순위` / `점수 공유`

## 실시간 통역 (전 세계 언어)

**데이터(인터넷) 없이도** 기본 여행·일상 표현을 오프라인 통역합니다.  
MIC로 말하면 번역 후 해당 언어로 읽어 줍니다. (말씀 끝난 뒤 약 2초 침묵 후 전송)

### 스톱할 때까지 번역 잠금
한 번 켜면 **한국말 → 그 언어만** 번역합니다. 다른 기능은 무시됩니다.

- `지금부터 스톱할 때까지 베트남어로 번역해줘`
- `내 말을 영어로 번역해줘`
- `일본어로만 번역`
- 끝: `스톱` / `그만` / `통역 종료`

한 문장만: `베트남어로 번역해 나는 이미 식사했어요` (이후에도 잠금이 이어집니다)

지원: 한·영·일·중·스·프·독·베트남 등. 온라인 번역 결과는 기기에 저장됩니다.

## 실시간 통계

숫자를 넣으면 AIZIO가 통계를 계산해 해답을 줍니다.

- `데이터 수익률 1.2 -0.5 3.1 0.8`
- `추가 2.0` (실시간 추가)
- `통계` / `평균` / `표준편차` / `승률`
- `확률 0 이상` (정규분포 가정)
- `상관 광고 매출` / `회귀 광고 매출`
- `시세기록 삼성전자` (실시간 시세 → 데이터셋)

생활 탭의 **STATS**에서 데이터셋·요약 리포트도 확인할 수 있습니다.
