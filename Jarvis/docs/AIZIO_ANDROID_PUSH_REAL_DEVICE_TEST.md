# Android Push Real Device Test (AIZIO)

**상태:** 실기기 검증 대기  
**Preview URL:** https://keen-drifter-97nqfnk.shipstatic.com

## 순서

1. Chrome에서 REVIEW_URL 열기  
2. 메뉴 → **앱 설치** / 설치 배너  
3. 런처에서 AIZIO 실행  
4. 설정 → 푸시 실기기 테스트  
5. 서버 URL 저장 → **서버 연결 확인**  
6. **권한·구독** (알림 허용)  
7. **1분 후 테스트 알림**  
8. 최근 앱에서 AIZIO **강제 종료**  
9. (선택) 화면 잠금 · 배터리 절약 모드  
10. 알림 수신·탭·딥링크 확인  
11. 예약 변경/취소 · 구독 해제·재구독  
12. 비행기 모드 → 복구 후 재동기화 확인  
13. 결과 복사 / 진단 JSON

## iPhone과 차이

| | Android | iPhone |
|--|---------|--------|
| 설치 | Chrome 설치 배너 | 공유→홈 화면 추가 |
| 종료 푸시 | Chrome/PWA 비교적 관대, OEM 배터리 최적화에 막힐 수 있음 | **홈 화면 PWA 필수** |
| 권한 | 알림 채널/중요도 | 설정→AIZIO 알림 |
