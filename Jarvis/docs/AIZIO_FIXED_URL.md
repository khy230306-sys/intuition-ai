# AIZIO 고정 주소

**공유·사용 주소는 이것 하나뿐입니다.**

## https://jarvis-app.shipstatic.com

별도의 `?nav=1` / `?customers=1` 주소를 나누어 쓰지 않습니다.  
앱을 연 뒤 **메뉴**에서 기능을 선택합니다.

### 사용 방법

1. https://jarvis-app.shipstatic.com 접속  
2. 하단 또는 상단 **메뉴** 탭  
3. 원하는 기능 선택  

| 메뉴 | 기능 |
| --- | --- |
| 길안내 | AIZIO 내부 지도 · 경로 |
| 손님관리 | 로컬 CRM |
| 일정 · 할 일 | 생활 |
| 가족 / 친구 | 소통 |
| 번역 | 글로벌 번역 |
| 설정 | API 키 · 푸시 · 진단 등 |

- 버전: 1.16.0+
- Preview 랜덤 URL은 공유하지 마세요.
- 재배포: `cd Jarvis && npm run deploy:web`
