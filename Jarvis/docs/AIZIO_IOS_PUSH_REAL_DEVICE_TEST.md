# iOS Push Real Device Test (AIZIO)

**상태:** 실기기 검증 대기 (코드/서버 준비 후 사용자가 확인)

**Preview URL:** https://keen-drifter-97nqfnk.shipstatic.com  
(자세한 메타: `docs/AIZIO_PREVIEW_DEPLOY.md`)  
**합격 조건:** 홈 화면에 추가된 PWA + 알림 허용 + 푸시 서버 연결 + **앱 완전 종료** 후 수신

Safari 탭만으로는 합격 처리하지 않습니다.

---

## 순서

1. Safari에서 REVIEW_URL 열기  
2. 공유 → **홈 화면에 추가** → 추가  
3. 홈 화면 **AIZIO** 아이콘으로 실행 (주소창 없는 standalone)  
4. 설정 → **실기기 테스트 모드 · 푸시**  
5. 푸시 서버 URL이 비어 있으면 HTTPS 서버 URL 입력 후 **설정 저장**  
6. **서버 연결 확인** → health OK  
7. **권한·구독** → 시스템 알림 허용  
8. **1분 후 테스트 알림** 예약  
9. 앱 전환기에서 AIZIO를 **위로 스와이프해 완전 종료**  
10. 화면 잠금(선택) 후 1분 대기  
11. 알림 수신 → 탭 → 앱 열림·채팅/일정 뷰  
12. 설정에서 예약 취소·구독 해제 재시험  
13. **테스트 결과 복사** / 진단 JSON 내보내기 (비밀키·endpoint 전체 없음)
