# AIZIO 메뉴 정리 (v1.23) — 실기기 확인 체크리스트

**Preview:** https://lightlab-92m8bq7.shipstatic.com  
**버전:** v1.23.0

## 새 하단 메뉴 (5개)

1. 홈  
2. 대화  
3. 일정  
4. 가족  
5. 더보기  

## 확인 순서

1. 앱 실행 → **홈**이 먼저 보이는지  
2. 홈에서 빠른 실행 6개 이하인지  
3. 홈 「AIZIO에게 말하기」→ 대화 이동  
4. 하단 **대화** → 음성·카메라·+ 만 보이는지  
5. 하단 **일정** → 오늘/일정/할 일/가족 필터  
6. 하단 **가족** → 구성원·오늘 일정·기능 보기  
7. 하단 **더보기** → 검색창에 `카메라` 입력 → AI 카메라 이동  
8. 더보기 → 설정 → Provider/진단 접근  
9. 이전 `#life` 북마크 → 일정 허브로 연결  
10. 앱 캐시만 새로고침 후 가족 데이터 유지  
11. 비행기 모드에서 하단 탭 이동  
12. 키보드 열림 시 하단 탭이 가리지 않는지  

각 항목: 정상 / 문제 있음
