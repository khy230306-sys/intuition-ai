# AIZIO Offline — Android 실기기 검증

**Preview만 사용.** `deploy:web` 금지.

## 순서

1. 온라인 상태에서 **Chrome**으로 Preview 열기
2. 메뉴 → **앱 설치** / 홈 화면에 추가
3. 설정 → 오프라인 사용 → 준비 완료 확인
4. 앱 종료
5. 비행기 모드
6. 설치 아이콘으로 실행
7. 기본 화면 이동 (HOME / 대화 / 생활 / 설정)
8. 로컬 데이터 생성 (할 일·메모)
9. 재실행 후 보존 확인
10. 연결 복구
11. 동기화·온라인 배지 확인

## 합격 기준

- 오프라인에서 설치 아이콘으로 앱이 열린다
- 로컬 데이터 보존
- 온라인 전용 기능은 안전한 실패 안내
