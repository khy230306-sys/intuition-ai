# AIZIO Offline — iPhone 실기기 검증

**Preview만 사용.** `deploy:web` 금지.

## 순서

1. Wi-Fi 또는 데이터 연결
2. Preview URL을 **Safari**에서 열기
3. 앱이 완전히 로드될 때까지 대기 (HOME v2 표시)
4. 설정 → **오프라인 사용** → **오프라인 준비 확인** → 「오프라인 실행 가능: 예」
5. 공유 → **홈 화면에 추가**
6. 홈 화면 **AIZIO** 아이콘으로 한 번 실행
7. 앱 완전 종료(앱 전환기에서 스와이프 업)
8. **비행기 모드** 켜기
9. Wi-Fi도 끄기
10. 홈 화면 AIZIO 아이콘 실행
11. HOME v2가 열리는지 확인 (Safari “페이지를 열 수 없음”이면 실패)
12. 대화 · 생활 · 가족 · 설정 이동
13. 일정 또는 메모 생성
14. 앱 종료 후 다시 실행
15. 데이터 유지 확인
16. 인터넷 복구
17. 대기 작업 동기화 / 배지 「온라인」 확인

## 구분

| 테스트 | 의미 |
| --- | --- |
| Safari 주소창에 오프라인 URL 입력 | SW 미제어 시 실패할 수 있음 — **설치 PWA와 별개** |
| 홈 화면 아이콘 | Offline-First의 핵심 성공 기준 |

## 합격 기준

- 비행기 모드에서 홈 화면 아이콘으로 **앱 셸이 열린다**
- 로컬 일정/메모가 유지된다
- 날씨/온라인 AI는 안내만 하고 앱이 죽지 않는다

**실기기 결과는 임의 합격 처리하지 않음 · Offline-First PWA 실기기 검증 대기**
