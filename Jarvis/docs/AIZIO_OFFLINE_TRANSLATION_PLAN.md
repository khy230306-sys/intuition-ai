# AIZIO Offline Translation Plan

## Tiers

1. **Online high-quality** — MyMemory (and future providers) when network is available
2. **Downloaded / built-in offline packs** — `offlineDict` travel & daily phrases (+ cache of prior online hits)
3. **No pack** — clear error, no invented text

## Settings → 오프라인 번역

Shows installed built-in packs (ko↔en/vi/ja/zh), sizes, and **언어팩 엔진 준비 필요** for neural offline engine.

- Wi-Fi-only download toggle reserved (disabled until engine ships)
- Delete / storage checks planned with engine integration
- Translate lock should use installed packs offline (phrase layer today)

## Non-goals (now)

- Fake neural translations
- Auto-saving all map tiles
- Claiming MIC STT works offline on iPhone Safari (cloud STT)
