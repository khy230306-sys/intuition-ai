# AIZIO Stage 7 — 아이폰 실기기 검증 체크리스트

**앱 안 경로:** 메뉴 → 설정 → **생활비서·카메라·가족 기능 진단** → 하단 체크리스트

**Preview:** https://lightlab-92m8bq7.shipstatic.com  
**버전:** v1.22.1 (진단 화면에서 확인)

## 순서

1. 앱 실행  
2. 버전 확인 (설정·진단 화면)  
3. 오늘의 브리핑 확인  
4. 채팅: `내일 오후 3시에 병원 일정 추가해줘`  
5. 생성된 일정 확인 (가족 도우미)  
6. 카메라 열기  
7. 문서/안내문 촬영  
8. OCR 결과 확인  
9. 일정 만들기 실행  
10. 가족 도우미 열기  
11. 가족 구성원 추가  
12. 가족 일정 추가  
13. 앱 완전 종료  
14. 다시 실행  
15. 데이터 복원 확인  
16. 비행기 모드에서 앱 실행  
17. 로컬 가족 일정 조회  
18. 온라인 복귀  
19. Vision 재시도 (키 있으면)  
20. 진단 JSON 내보내기  

각 항목에 **정상 / 문제 있음**을 앱에서 표시할 수 있습니다.

## 자동 진단

같은 화면의 **3개 기능 전체 자동 진단** 버튼은 Mock·로컬만 사용하며, `[진단테스트]` 태그가 붙은 임시 데이터만 생성·삭제합니다.
