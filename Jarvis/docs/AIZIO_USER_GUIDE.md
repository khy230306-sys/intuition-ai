# AIZIO 사용설명서 (간단)

**AIZIO(아이지오)** 는 말로 쓰는 일상 비서 앱입니다.

채팅창에 적거나 MIC로 말하면, 날씨·할 일·알림·투자·번역·메모를 대신 챙겨 줍니다.

## 이렇게 써 보세요

| 말하기 / 치기 | 하는 일 |
| --- | --- |
| 오늘 날씨 알려줘 | 날씨 |
| 브리핑 | 오늘 요약 |
| 할 일 장보기 추가 | 할 일 |
| 알림 30분 뒤 약 | 로컬 알림 |
| 삼성전자 시세 | 주식 시세 |
| 일본어로 번역해 안녕하세요 | 번역 |
| 조용한 음악 틀어줘 | 음악 |
| 사용설명서 | 이 안내 |
| API 키 | AI 키 발급·입력 안내 |
| 도움말 | 명령어 전체 목록 |

## 화면 아래 탭

- **채팅** — 대화와 음성
- **생활** — 할 일 · 장바구니 · 지출 · 습관 · 일기
- **투자** — 시세 · 관심종목 · 포트폴리오
- **가족 / 친구** — 코드로 함께 쓰는 공간
- **게임** — 오프라인 미니게임
- **설정** — 이름 · AI 연결 · 앱 캐시

## API 키 활용 · 발급 · 입력

### 키가 왜 필요한가요?

| 구분 | 예시 | API 키 |
| --- | --- | --- |
| 로컬 기능 | 날씨, 시세, 할 일, 알림, 메모, 번역 잠금 | **불필요** |
| 자유 대화 | 잡담, 긴 설명, 복잡한 질문 | **있으면 더 자연스러움** |

AIZIO는 특정 유료 API에 묶이지 않습니다. **본인 키**를 기기에만 저장해 사용합니다. 운영자 공용 키는 앱에 들어 있지 않습니다.

### 추천 순서 (무료로 시작)

1. **OpenRouter** — 기본 무료 모델 `openrouter/free` (한도 있음)
2. **Gemini** — Google AI Studio 키
3. **Groq** — 빠른 무료 티어
4. **OpenAI** — 유료 API (ChatGPT Plus 구독 ≠ API 결제)

### 발급 사이트

- OpenRouter: https://openrouter.ai/keys
- Gemini: https://aistudio.google.com/apikey
- Groq: https://console.groq.com/keys
- OpenAI: https://platform.openai.com/api-keys

### 앱에 입력하는 방법

1. 하단 탭 **설정**을 엽니다.
2. **AI 연결 (Hybrid Provider)** 카드에서 제공할 AI를 고릅니다.
3. 위 사이트에서 키를 만들고 **복사**합니다.
4. 설정 칸에 붙여넣고 모델을 확인한 뒤 **설정 저장**을 누릅니다.
5. **연결 테스트**로 동작 여부를 확인할 수 있습니다.
6. (선택) **자동 선택**이면 무료 쪽을 순서대로 시도합니다. **유료 자동 사용**은 기본이 꺼져 있습니다.

첫 실행 시 나오는 AI 안내(위자드)에서 「무료 AI로 시작」을 눌러도 같은 설정 화면으로 이동합니다.

### 주의

- 키를 **채팅창에 붙여넣지 마세요.** 설정에만 입력하세요.
- 키를 다른 사람과 공유하지 마세요. 유출되면 해당 사이트에서 폐기·재발급하세요.
- 무료 한도는 제공사 정책에 따라 바뀌며, **무제한이 아닙니다.**
- 키가 없어도 일정·할 일·날씨·시세 등 로컬 기능은 그대로 씁니다.

## 알아 두면 좋아요

- 날씨·시세·할 일·알림 등은 **API 키 없이** 동작합니다.
- 자유 대화는 설정에서 **무료 AI**(OpenRouter / Gemini / Groq) 또는 OpenAI를 연결하면 더 편합니다.
- 투자 정보는 참고용이며, 투자 조언이 아닙니다.

앱 안에서는 홈 칩 **「사용설명서」** 또는 채팅에 `사용설명서` / `API 키` 라고 입력하면 안내를 볼 수 있습니다.
