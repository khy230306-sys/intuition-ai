# AIZIO 사용설명서 (간단)

**AIZIO(아이지오)** 는 말로 쓰는 일상 비서 앱입니다.

채팅창에 적거나 MIC로 말하면, 날씨·할 일·알림·투자·번역·메모를 대신 챙겨 줍니다.

## 이렇게 써 보세요

| 말하기 / 치기 | 하는 일 |
| --- | --- |
| 오늘 날씨 알려줘 | 날씨 |
| 브리핑 | 오늘 요약 |
| 할 일 장보기 추가 | 할 일 |
| 알림 30분 뒤 약 | 로컬 알림 |
| 삼성전자 시세 | 주식 시세 |
| 일본어로 번역해 안녕하세요 | 번역 |
| 조용한 음악 틀어줘 | 음악 |
| 사용설명서 | 이 안내 |
| 도움말 | 명령어 전체 목록 |

## 화면 아래 탭

- **채팅** — 대화와 음성
- **생활** — 할 일 · 장바구니 · 지출 · 습관 · 일기
- **투자** — 시세 · 관심종목 · 포트폴리오
- **가족 / 친구** — 코드로 함께 쓰는 공간
- **게임** — 오프라인 미니게임
- **설정** — 이름 · AI 연결 · 앱 캐시

## 알아 두면 좋아요

- 날씨·시세·할 일·알림 등은 **API 키 없이** 동작합니다.
- 자유 대화는 설정에서 **무료 AI**(OpenRouter / Gemini / Groq 등)를 연결하면 더 편합니다.
- 투자 정보는 참고용이며, 투자 조언이 아닙니다.

앱 안에서는 홈 칩 **「사용설명서」** 또는 채팅에 `사용설명서` 라고 입력하면 같은 안내를 볼 수 있습니다.
