# 3번 엔진 로직 (Engine3)

## 목적
3번 엔진은 1번 엔진의 방향을 기본으로 하고,
2번 엔진이 예상하는 성공/실패에 따라 방향을 **유지 또는 반전**합니다.

## 방식(현재 구현)
1. 2번 엔진이 `SUCCESS`라고 판단하면:
   - 1번 엔진의 방향을 그대로 유지
2. 2번 엔진이 `FAIL`이라고 판단하면:
   - 기본적으로 1번 방향을 반전
3. 과도한 반전/쏠림 방지를 위해, 최근 PLAYER 비율의 bias가 크면
   - 반전 조건을 강화(2번 성공확률이 충분할 때만 반전)하거나
   - 대신 관망/유지로 완화합니다.

## ENTRY/WAIT
- `allowWait`가 켜져 있으면 3번 엔진의 신뢰도가 기준(0.58) 미만일 때 WAIT로 표시합니다.
