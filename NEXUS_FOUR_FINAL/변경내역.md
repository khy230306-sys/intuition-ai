# 변경내역

## NEXUS FOUR FINAL 구현 상태

이 작업 환경에서는 **기존 NEXUS FOUR v3 / `nexus_v3.zip` 소스를 찾지 못했습니다.**
따라서 본 프로젝트는 스펙을 기준으로 **새로 구현**되었습니다.

## 주요 추가 기능
- React + TypeScript (Vite) 기반 UI
- PWA(manifest + service worker) 구성
- IndexedDB(Dexie) 영구 저장/JSON 백업/복원
- PLAYER/BANKER/TIE 입력 + Undo + 새 슈
- 1/2/3 엔진 + 랜덤 기준 + AI 밸런스 엔진
- 종합 멀티 엔진(Wilson 하한 기반 점수 + 최소 표본 필터 + 히스테리시스)
- 마틴 시스템(사이클 잠금/단계 상승/성공 시 리셋/TIE 0손익)
- WebSocket 스캐너 프로토콜 호환(수신 적재, 자동배팅은 연결 상태에서만 전송)
- Electron Windows 래퍼(main preload 포함) 및 Windows portable 타겟 빌드 시도
