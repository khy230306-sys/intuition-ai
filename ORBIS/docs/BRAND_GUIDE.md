# ORBIS Brand Guide

## 브랜드명

**ORBIS**

## 슬로건

**Every Round Creates a New Story**

한국어 보조 문구: 새로운 세계를 체험하세요

## 브랜드 방향

- 미래적
- 고급스러움
- 신비로움
- 우주와 에너지 궤도
- 싸구려 슬롯머신 / 기존 카지노 UI 복제 금지

## 로고 사용법

- SVG로 제작된 원형 궤도 + CORE 심볼과 ORBIS 워드마크를 사용합니다.
- 작은 화면에서는 심볼만으로도 식별 가능해야 합니다.
- favicon / PWA 아이콘은 단순화된 CORE+궤도 버전을 사용합니다.
- 외부 상표나 기존 카지노 로고를 복사하지 않습니다.
- 로고 주변 여백을 확보하고, 과도한 왜곡/그림자 남용을 피합니다.

## 디자인 원칙

1. 깊이감 있는 우주 배경과 절제된 네온 글로우
2. CSS transform / opacity 중심의 부드러운 모션
3. 모바일 우선, 터치 영역 최소 44px
4. 정보보다 분위기와 브랜드 인상을 우선하되 가독성 유지
5. 성능이 떨어지지 않도록 파티클과 효과를 제한

## Orb 상징

- **BLUE**: 집중과 흐름
- **GOLD**: 균형과 가치
- **VIOLET**: 직관과 변화

## CORE

CORE는 ORBIS의 중심 에너지입니다. 느린 회전과 Pulse로 생명감을 표현하며, 모든 Orb의 기준점이 됩니다.
