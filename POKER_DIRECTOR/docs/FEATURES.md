# Features

## 완료된 MVP 기능

- 역할: 관리자 / 디렉터 / 스태프 / 플레이어 조회
- 로컬 데모 모드 + Supabase 클라우드 전환 구조
- 대시보드 (진행/예정/종료, 인원, 상금, 빠른 액션)
- 토너먼트 생성 (포맷, 리바이/리엔트리/애드온, 블라인드 템플릿)
- 블라인드 구조 편집기 (추가/삭제/복제/순서/템플릿/브레이크)
- 참가자 등록/검색/CSV/체크인/탈락/리바이/리엔트리/애드온
- 좌석 자동 배정 미리보기·확정
- 절대시각 기반 블라인드 타이머 (백그라운드/새로고침 복구)
- TV 전용 디스플레이 (테마 4종, 전체화면)
- 테이블 관리, 이동, 교환, 밸런싱 추천, 테이블 브레이크
- 상금 계산 및 합계 검증
- 공지 / 딜러 호출
- 기록·통계 / CSV / 인쇄
- 플레이어 코드 조회 화면
- Undo·감사 로그, 백업/복구, 오프라인 IndexedDB 저장
- PWA manifest + service worker
