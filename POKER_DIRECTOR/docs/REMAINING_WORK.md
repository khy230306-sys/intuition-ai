# Remaining Work

MVP에서 의도적으로 남겨두거나 클라우드 연동 후 확장할 항목:

1. Supabase Auth 이메일 로그인 UI 완성 (현재 구조/클라이언트만 준비)
2. 엔티티 단위 realtime subscription (현재 스냅샷 sync 인터페이스)
3. 플레이어 전화번호를 위한 DB column privilege / secure view
4. 음성 안내 브라우저 호환성 보완(커스텀 오디오 파일 팩)
5. 다중 탈락 동시 순위 드래그 정렬 UI 고도화
6. 실제 매장 로고 업로드 스토리지 연동
7. E2E(Playwright) 자동화 확대
