# Security

- 데모 비밀번호는 환경변수로만 주입하며, 클라우드 모드에서는 Supabase Auth로 전환하는 구조를 사용합니다.
- `.env`는 Git에 포함하지 않습니다.
- 전화번호 등 개인정보는 관리자 화면에만 표시합니다.
- 플레이어 조회는 access code 기반이며 타인 정보를 노출하지 않습니다.
- 주요 운영 액션은 `audit_logs`에 기록합니다.
- 삭제는 소프트 삭제(`deletedAt`/`cancelled`)를 우선합니다.
- 상금 합계 검증으로 금액 불일치를 차단합니다.
- 이 소프트웨어는 합법 토너먼트/이벤트 운영용이며 불법 도박·온라인 베팅·자동 베팅 기능을 포함하지 않습니다.
