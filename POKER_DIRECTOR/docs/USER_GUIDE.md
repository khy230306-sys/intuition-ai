# 사용 가이드

## 1. 로그인

데모: `admin` / `1234`

## 2. 대시보드

진행 중 토너먼트와 인원/상금을 확인하고 **타이머**, **참가자**, **TV 화면**으로 이동합니다.

## 3. 타이머

시작 → 일시정지/재개 → 다음 레벨. TV 화면을 별도 모니터에 띄워 두면 조작이 즉시 반영됩니다.

## 4. 참가자

개별/일괄/CSV 등록 후 체크인 → 좌석 미리보기 → 확정. 상세에서 탈락/리바이/리엔트리/애드온 처리.

## 5. 테이블

밸런싱 추천을 확인한 뒤 적용. 인원이 줄면 테이블 브레이크 추천을 확정합니다.

## 6. 상금

템플릿 적용 후 합계가 총 상금과 일치할 때만 저장됩니다.

## 7. 플레이어 조회

참가자 상세의 액세스 코드를 `/player/:code`로 공유합니다. 전화번호 등 타인 정보는 노출되지 않습니다.
