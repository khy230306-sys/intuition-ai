# POKER DIRECTOR 사용 설명서

앱 안에서도 같은 내용을 볼 수 있습니다: **더보기 → 사용 설명서** (`#/help`)

## 빠른 시작 (1분)

1. `admin` / `1234` 로그인 (또는 「데모 계정으로 바로 입장」)
2. 하단 **타이머** → **시작**
3. **더보기 → 게임 금액 설정**에서 바이인·리바이 금액 수정
4. **참가자** 등록, **테이블** 밸런싱, **TV 화면** 확인

## 화면별 안내

### 홈(대시보드)
- 오늘 진행/예정/종료 토너먼트, 남은 인원, 총 상금 확인
- 새 토너먼트 / 금액 설정 / 사용 설명서 / TV 화면 바로가기

### 게임 금액 설정 (`#/money`)
- 바이인, 참가비, 보장 상금, 시작 스택
- 리바이 / 리엔트리 / 애드온 비용·지급 칩·횟수
- 바운티 금액, 운영비, 추가 상금
- 저장 시 상금이 다시 계산됩니다

### 타이머
- 시작 / 일시정지 / 다음·이전 레벨
- 분·초 입력, `12:30` 형식, +/- 1·5분
- TV 전체 화면 열기
- 새로고침·백그라운드에서도 실제 시간으로 복구

### 참가자
- 개별/일괄/CSV 등록
- 체크인, 탈락, 리바이, 리엔트리, 애드온
- 좌석 미리보기 → 확정
- 조회 코드로 플레이어 화면 공유

### 테이블
- 수동 이동, 좌석 교환
- 밸런싱 추천 → 적용
- 테이블 브레이크 추천 → 확정
- 파이널 테이블 추첨

### 상금 계산
- 템플릿 적용 또는 퍼센트/금액 직접 수정
- 합계가 총 상금과 같을 때만 저장

### TV / 플레이어
- TV: `#/display/tournament/:id`
- 플레이어: `#/player/:accessCode`

## 모바일

- 화면이 길면 위아래로 스크롤하세요 (하단 메뉴 여백 적용됨)
- iPhone Safari: 공유 → 홈 화면에 추가
- Android Chrome: 메뉴 → 앱 설치 / 홈 화면에 추가
