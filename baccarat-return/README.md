# Baccarat Return · 복귀

바카라 대로표 사진을 올리면 패턴을 기억하고, 처음부터 B/P를 하나씩 맞춰가는 **복귀 연습 PWA**입니다.

도라짓고땡 PICK AI와 같은 모바일 우선 스타일·구조로 만든 독립 앱입니다. 데이터는 브라우저(LocalStorage)에만 저장됩니다.

## 로컬 실행

```bash
cd baccarat-return
npm install
npm run dev
```

- 개발: `http://localhost:5174/`
- 미리보기: `npm run build && npm run preview`

## 사용법

1. **사진 업로드** — 로비/테이블 대로표를 올리면 빨간(B)·파란(P) 패턴을 읽습니다.
2. **패턴 확인** — 인식 결과를 수정한 뒤 **복귀 시작**.
3. **하나씩 맞추기** — B/P 입력 시:
   - 맞으면 **대로표**에 정답이 한 칸씩 표시되고 성공 표에 **O**
   - 틀리면 실패 표에 **X** 후 세션 종료
4. **타이(T)** — 「타이」라고만 안내하며 성공/실패·대로표 판정에는 넣지 않습니다.

## iPhone 홈 화면 설치

1. Safari로 HTTPS 앱 URL을 엽니다.
2. 공유(□↑) → **홈 화면에 추가**.
