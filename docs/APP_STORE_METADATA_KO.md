## 앱 설명

로또렌즈는 동행복권 실제 당첨 이력을 바탕으로 번호 통계와 패턴을 살펴보는 AIZIO의 분석·엔터테인먼트 앱입니다.

주요 기능
- 출현 히트맵, 핫/콜드, 회귀 대기 번호
- 홀짝·저고·합계·연속수·동반 페어 통계
- 회차 간 흐름(이월·평균회귀·전이) 분석
- 전략형 번호 추천과 내 번호 적합도 점검
- 회차 아카이브 검색

중요 안내
본 서비스는 통계 및 엔터테인먼트 목적으로 제공되며 복권 당첨을 보장하지 않습니다.  
로또렌즈는 실제 복권 판매·구매·결제·베팅 기능을 제공하지 않습니다.

## App Review Notes 초안

This app (LottoLens / 로또렌즈) is an on-device statistics and entertainment tool for reviewing historical Korean Lotto 6/45 draw patterns.

- No lottery ticket sales, purchases, payments, betting, deposits, or payouts
- No links to gambling sites
- No account, ads, or tracking SDKs
- Analysis data is bundled in the app; core features work offline
- Disclaimer is shown in the app footer stating results are not guaranteed

Please evaluate it as an entertainment/utility analysis app, not as a gambling or lottery-sales product.
