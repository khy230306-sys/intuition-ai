# 로또렌즈 (LottoLens) — iOS 패키징 사전 분석

조사 기준: `lotto-analyzer/` 실제 소스 (브랜치 `cursor/lottolens-ios-appstore-ready-f99e`)

## 스택

| 항목 | 상태 |
|------|------|
| 빌드 | Vite 7 + TypeScript |
| 출력 | `dist/` (`base: './'`) |
| PWA | `manifest.webmanifest` 있음, **service worker 없음** |
| 아이콘 | `favicon.svg`, `apple-touch-icon.png` (180×180, 저해상도) |
| 런타임 의존성 | 없음 (순수 TS) |

## 기능 요약

- 동행복권 당첨 데이터(`src/data/draws.json`) 기반 통계·히트맵·흐름 분석
- 전략형 번호 추천 / 내 번호 점검 / 회차 아카이브 검색
- 데이터는 **앱 번들에 내장** → 오프라인에서도 핵심 화면 동작
