# 격파

모바일 세로 스크롤 **슈팅 게임** (축구 아님).

드래그로 기체 이동, 자동 사격. 웨이브·보스·파워업·스테이지 해금·랭킹·일일 미션·메달.

## 실행

```bash
cd gyeokpa
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

## 조작

- 화면을 드래그해 이동
- 자동 연사
- 스테이지 10개
- 아이템: 무기 강화 / 라이프 / 실드 / 폭탄 / 레이저 / 아군
- 레이저: 화면 끝까지 관통 빔, 획득 시 7초 후 이전 무기로 복귀 (추가 획득 시 최대 3줄)
- 아군: 우리 편 기체 1기 추가, 최대 3기, 각 약 10초 후 이탈
