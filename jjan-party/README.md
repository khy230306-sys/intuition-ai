# 짠! — 술자리 벌칙 게임

여러 술게임을 한곳에 모은 모바일 친화 웹앱입니다.

## 포함된 게임

| 게임 | 설명 |
|------|------|
| **벌칙 룰렛** | 랜덤 대상 + 벌칙 미션 |
| **밸런스 전쟁** | A/B 투표, 소수파 마시기 |
| **폭탄 돌리기** | 비밀 타이머, 터질 때 들고 있는 사람 |
| **미션 카드** | 랜덤 챌린지 성공/실패 |
| **초성 퀴즈** | 맞히거나 마시기 |
| **눈치 게임** | 숫자 외치기, 마지막/겹침 벌칙 |
| **취중진담** | 솔직 답변 or 패스 벌칙 |
| **가위바위보** | 두 명 대결, 패자 마시기 |
| **금지어** | 배정 단어 말하면 즉시 벌칙 |

**혼돈 모드**로 위 게임 중 6개를 랜덤 연쇄 실행할 수 있습니다.

## 실행

```bash
cd jjan-party
npm install
npm run dev
```

빌드:

```bash
npm run build
npm run preview
```

## 사용 팁

1. **멤버 모으기**에서 이름 2명 이상 등록
2. 허브에서 개별 게임 선택, 또는 **혼돈 모드**
3. 벌칙이 적용되면 잔 수가 자동 집계 (로컬 저장)

건배. 짠!
