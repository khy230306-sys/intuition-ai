# 로또렌즈

동행복권 **실제 당첨 데이터**(1회~최신)를 바탕으로 빈도·공백·페어·패턴 통계를 분석하고, 전략별 스마트 번호를 추천하는 웹 앱입니다.

## 모바일 접속 주소 (아이폰 · 안드로이드)

**최신 빌드:** 항상 [LATEST_BUILD.md](./LATEST_BUILD.md) 를 보세요.

**https://pnly0n2h.nivii.app**

휴대폰 브라우저(Safari / Chrome)에서 바로 열 수 있습니다.  
아이폰: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 홈 화면에 추가

## 기능

- 출현 히트맵, 핫/콜드, 회귀 대기 번호
- **순서·흐름 분석**: 회차 이월, 합계 평균회귀, 정렬 자리 골격, 전이(Markov) lift
- 홀짝·저고·합계·연속수·AC·동반 페어 통계
- 전략형 추천: 균형 / 흐름 / 핫 / 콜드 / 회귀 / 페어
- 내 번호 패턴 적합도 점검
- 회차 아카이브 검색

## 실행

```bash
npm install
npm run dev
```

데이터 갱신(동행복권 API):

```bash
npm run fetch-data
```

## 빌드

```bash
npm run build
npm run preview
```

## 주의

로또는 독립적 무작위 추첨입니다. 통계 분석은 오락·학습 목적이며 당첨을 보장하지 않습니다.
