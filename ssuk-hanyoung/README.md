# 쑥쑥놀이터 (ssuk-hanyoung)

한영이를 위한 **자동차 · 색깔** 중심 유아 놀이 웹앱입니다.

기존 [ssuk-hanyoung.vercel.app](https://ssuk-hanyoung.vercel.app/) 경험을 바탕으로, 자동차·색깔을 좋아하는 아이를 위해 새 게임을 대폭 추가한 버전입니다.

## 새 놀이

- 색깔 차고 — 같은 색 차고에 자동차 넣기
- 부릉부릉 레이스 — 말한 색깔 자동차 탭하기
- 주차 놀이 — 색깔 자리에 주차하기
- 자동차 색칠공장 — 차체 색칠
- 자동차 조립 — 차종 + 색깔 맞추기
- 색깔 자동차 찾기
- 색깔 섞기
- 자동차 기억카드 / 자동차 소리
- 신호등 · 세차 · 풍선 · 버스 세기 · 색깔 퀴즈

## 실행

```bash
cd ssuk-hanyoung
npm install
npm run dev
```

## 배포 (Vercel)

이 폴더를 Vercel 프로젝트 루트로 연결하면 됩니다 (`vercel.json` 포함).

```bash
npm run build
```
