# 쑥쑥 색칠놀이 — 경쟁/레퍼런스 조사 V1

**목적:** 현재 TEMP 기하학 선화(“빨간/파란 자동차가 같은 실루엣”)는 **목표 그래픽이 아님**을 인정하고,  
비슷한 상용 키즈 색칠·자동차 콘텐츠의 **이미지 품질 기준**과 **프로그램 시스템**을 모아 다음 결정을 돕는다.

**원칙:** 이 문서 단계에서 조악한 SVG를 추가 생성하지 않는다. GRAPHIC FREEZE 유지.

---

## 1. 현재 쑥쑥 화면이 부족한 이유 (합의)

스크린샷의 카드들은:

| 문제 | 설명 |
|---|---|
| Flat outline | 검정 외곽선 + 평면 파스텔 채움 |
| 동일 실루엣 반복 | 색만 다른 “같은 세단” 7장 |
| 캐릭터성 없음 | 큰 눈·표정·장난감 비율 부재 |
| TEMP 배지 | 완성 그래픽이 아님을 스스로 표시 |
| 프리미엄 3D 감성 없음 | 하이라이트·소프트 섀도·통일 광원 없음 |

→ **시스템(부분 색칠/저장)과 별개로, 썸네일·선화 자체가 상품 가치가 없음.**

---

## 2. 비교할 콘텐츠 유형 (우리가 벤치할 축)

| 축 | 질문 |
|---|---|
| **Art** | 썸네일/완성본이 “갖고 싶은 장난감 차”처럼 보이는가? |
| **Line art** | 색칠용 선화가 깨끗하고 영역이 큰가? |
| **Fill UX** | 탭 채우기 / 브러시 / 번호 색칠 중 무엇을 쓰는가? |
| **Tools** | 도구가 실제로 다르게 느껴지는가? |
| **Library** | 페이지 수·카테고리·난이도 래더 |
| **Reward loop** | 갤러리·완성 연출·다시 하고 싶은가? |
| **Age fit** | 3–4세 vs 6–7세 분기 |

## 3. 레퍼런스 앱 · 콘텐츠 (요약)

### A. 차량 특화 색칠 (직접 경쟁)

#### Car Coloring Games for Kids (BasiApps / Play)
- **콘텐츠:** 120+ 차량 페이지, 매일 신규 페이지, 레이스/몬스터트럭/소방·경찰/중장비/버스 등
- **시스템:** Easy tap-to-color, Undo/Redo, 저장 갤러리, 완성→퍼즐 변환, Glow/Neon·글리터·패턴 필
- **난이도:** Easy(3–4) / Medium(5–6) / Hard(7–10) — **페이지 복잡도**로 성장
- **철학:** Paint-by-number 강제 없음 (창의 자유)
- **시사점:** 라이브러리 양 + 난이도 래더 + “매일 새 도안”이 반복 플레이 엔진

#### Colour & Draw Cars for Kids (App Store)
- **콘텐츠:** 100+ 페이지, **9개 차량 카테고리** (중장비/구조/버스·기차/레이스/전기차/몬스터/클래식/견인/커스텀)
- **시스템:** 탭 색칠 + paint-by-number + color match + 자유 doodle + step-by-step draw
- **도구:** crayon / pencil / spray 등 복수 도구
- **연령:** 2–6 강조, offline
- **시사점:** 카테고리 IA가 쑥쑥과 거의 동일 방향 → **우리는 카테고리만 있고 도안 품질·양이 빈약**

#### Coloring: Trucks & Cars
- **강조:** “stunning / handpicked illustrations”, 광고·트래킹 없음
- **시사점:** 마케팅 핵심이 **일러스트 품질** — 기능 목록보다 그림이 상품

#### Monster Truck & Cars / Mixer Truck Coloring 계열
- 저가·광고형 다수. 기능은 비슷해도 **아트 통일성·브랜드 감성**에서 상위 앱과 격차
- 시사점: “차 색칠 앱”은 시장에 많음 → **차별화는 세계관 캐릭터 + 학습/보상 연결**

### B. 프리미엄 키즈 크리에이티브 (품질 천장)

#### Crayola Create & Play
- **아트 도구:** 실제 크레용/마커 질감에 가까운 스트로크 (레이어·텍스처)
- **구조:** Coloring book + Free draw + (카메라 꾸미기) + 개인 갤러리
- **콘텐츠:** 테마 페이지 대량 + 월간 업데이트 (구독)
- **시사점:**  
  1) 도구 “느낌”이 제품의 절반  
  2) 갤러리는 삭제보다 **모으는 자부심**  
  3) 색칠만이 아니라 **크리에이티브 스테이션**

#### Sago Mini (Bug Builder 등)
- 탭·페인트 후 **생명 부여(애니·사운드·사진)**  
- 팔레트는 적어도 **결과물이 항상 귀엽게** 나오도록 설계
- **시사점:** 완성 후 “차가 반응”하는 juice가 쑥쑥 celebrate와 같은 축 — 단 아트가 받쳐야 함

#### Recolor (성인/가족 색칠)
- 전문가 도안 수천 장, 팔레트·이펙트·커뮤니티
- 키즈 전용은 아니나 **“도안 품질 = 제품”** 극단 사례

#### Disney Color and Play
- 색칠 → 3D/AR 연동 시도
- UX/스캔 이슈 리뷰 많음 → **화려한 약속보다 터치 신뢰성이 먼저**

### C. 아트 스타일 레퍼런스 (이미지 방향)

사용자가 원한 방향과 가까운 키워드:

- **Cute toy car character / friendly cartoon vehicle**
- 큰 눈, 둥근 차체, 과장된 휠, 따뜻한 PBR/소프트 하이라이트
- Pixar *Cars*급 사실성은 과하고, **장난감 쇼룸 + 캐릭터 얼굴**이 목표
- 마켓플레이스에는 “Cute Car Coloring Pages”, “Bold & Easy Vehicles” 팩이 많으나  
  **품질·라이선스·세계관 통일**이 제각각 → 그대로 쓰면 스타일 혼합 위험 (GRAPHIC FREEZE와 충돌)

**권장 아트 파이프라인 (코드가 아님):**
1. 스타일 바이블 1장 (눈·광원·비율·외곽선 두께)
2. 차량당 **REFERENCE(채색 완성 3D/2.5D)** + **LINE ART(영역 분리 가능 선화)** 페어
3. 영역 마스크/레이어 ID 규약 (`body`, `door`, `window`…)
4. 승인 후에만 Registry `TEMP → REAL`

## 4. 시스템이 공통으로 쓰는 패턴

| 패턴 | 상용에서 흔한 형태 | 쑥쑥 현재 | 갭 |
|---|---|---|---|
| 도안 선택 | 카테고리 → 썸네일 그리드 (고퀄 미리보기) | 카테고리+TEMP 배지 | 썸네일 품질 |
| Easy fill | 닫힌 영역 탭 채우기 | 있음 (SVG region) | OK 방향 |
| Free draw | 브러시 레이어 | 있음 | 질감·클리핑 강화 여지 |
| Paint-by-number | 옵션 가이드 | 구조만 | 도안 품질 선행 |
| 도구 | 크레용/마커/채우기/지우개 | 6종 | 질감·프리셋 팔레트 |
| 난이도 | Easy/Med/Hard **도안** | difficulty 필드만 | 도안 복잡도 실반영 필요 |
| 갤러리 | 저장·공유·재편집 | 저장/계속/복사/삭제 | 공유·액자 연출 |
| 완성 juice | 반짝임·사운드·애니 | confetti+캐릭터 | 차량별 반응은 약함 |
| 콘텐츠 양 | 100–1000 페이지급 마케팅 | 플레이 가능 ~20 | **치명적 부족** |
| 업데이트 | 매일/매월 새 도안 | 없음 | 운영 모델 미정 |

## 5. “고퀄리티 이미지” 체크리스트 (승인 기준 초안)

한 장이 REAL이 되려면:

1. **한눈에 차종 인식** (소방차/굴착기/스쿨버스…)
2. **통일 세계관** (눈·입·광원·채도 톤 동일 시리즈)
3. **2.5D~3D toy shading** (소프트 하이라이트, 과하지 않은 그림자)
4. **둥근 장난감 비율** (사실적 세단 실루엣 금지)
5. **표정/캐릭터** (최소한 얼굴 요소)
6. **색칠용 선화**는 영역이 크고(3–4세), 선이 깨끗
7. **썸네일에서도** TEMP flat이 아니라 “갖고 싶은 차”로 보임
8. 모바일에서 선명 (권장 원본 ≥1024px, WebP)
9. emoji / clip-art / 임의 SVG 양산 금지
10. 라이선스·출처 명확 (사내 제작 또는 구매·승인 팩)

## 6. 프로그램 시스템에서 가져올 것 / 버릴 것

### 가져올 것 (이미 방향이 맞거나 강화)
- 영역 탭 채우기 + 자유 브러시 이중 모드
- 카테고리 IA (자동차/구조/버스·트럭/중장비/특수)
- Undo/Redo, 갤러리, 창의(정답 없음)
- 난이도·연령 메타데이터

### 버릴 것 / 중단
- **색만 다른 동일 세단 카드 7장**을 “콘텐츠 7개”로 세는 것
- TEMP 기하학 선화를 제품 썸네일로 전면 노출하는 UX
- “차량 숫자”만 늘리고 ART_REQUIRED 카드로 선반을 채우는 인상

### 다음에 추가할 시스템 (아트 확보 후)
- Easy/Med/Hard **도안 세트** 분리
- 완성 progress (영역 N개 중 M개 칠함 — 강요 없는 게이지)
- 완성 → 짧은 차량 애니 + 선택적 퍼즐/스티커 보상 (Basi/Crayola류)
- 월간/시즌 도안 드롭 파이프라인

## 7. 쑥쑥 vs 상용 — 한 장 비교

| | 상용 차량 색칠 앱 | Crayola급 | 쑥쑥 현재 |
|---|---|---|---|
| 그림 | 고유 일러스트 다수 | 브랜드 일러스트 | TEMP flat / 동일실루엣 |
| 페이지 수 | 100+ | 수백+ | ~20 playable |
| 탭 채우기 | 표준 | 있음 | 있음 |
| 도구 질감 | 보통~좋음 | 매우 좋음 | 기본 차별 |
| 갤러리 | 표준 | 강함 | 기본 |
| 세계관 캐릭터 | 약함~중간 | 강함 | 한이/영이는 있으나 차 아트와 분리 |
| 학습 연결 | 약함 | 중간 | Learning Core 있음 (강점 가능) |

**결론:** 쑥쑥의 기회는 “또 하나의 차 색칠 앱”이 아니라  
**한이/영이 + Learning + 부분 색칠 스튜디오**를 **프리미엄 차량 캐릭터 아트**로 포장하는 것.  
지금은 아트가 병목이다.

## 8. 추천 다음 스텝 (코드보다 아트 결정)

1. **스타일 레퍼런스 보드 확정** (원하시는 느낌의 이미지 3~6장 — 외부 링크/첨부)
2. **파일 규약 확정**
   - `reference.webp` (완성)
   - `lineart.webp` 또는 layered SVG/PNG masks
   - `regions.json` (폴리/마스크 ID)
3. **파일럿 6대만 REAL 제작**  
   예: 빨간차, 소방차, 경찰차, 스쿨버스, 덤프트럭, 굴착기  
   → 이 6개가 썸네일·색칠 화면에 들어가면 제품이 바뀜
4. TEMP 동일 세단 7장 UI에서 **숨기거나 “샘플/개발용” 처리**
5. 그 다음에야 도구 질감·완성 애니를 상용 수준으로 밀기

## 10. 한 줄 정리

**지금 필요한 건 코드가 아니라 “승인된 프리미엄 차량 캐릭터 아트 페어(완성본+영역 선화)”다.**  
시스템 골격은 이미 그 아트를 꽂을 수 있게 열려 있다.  
TEMP flat 카드는 목표 그림이 아니며, 더 만들지 않는 것이 맞다.
