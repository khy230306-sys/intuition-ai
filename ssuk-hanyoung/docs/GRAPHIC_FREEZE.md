# GRAPHIC FREEZE (쑥쑥놀이터)

**상태: ACTIVE**  
**발효:** 2026-08-07  
**해제:** 별도 승인(명시적 지시) 전까지 유지

## 목적

상용 키즈앱 수준의 시각 일관성을 지키기 위해,  
승인되지 않은 일러스트·스타일 혼합·가짜 완료 처리를 금지한다.

## 동결 범위

다음을 **임의로 생성·변경·교체하지 않는다** (승인 파일 전달 시에만 예외):

- 캐릭터 (한이/영이 및 상태)
- 동물 / 음식 / 장소 / 카테고리 / 감정 일러스트
- 신규 테마 일러스트 팩
- 기존 **승인 REAL** 이미지의 재디자인·재처리

## 금지 행위

1. 임의 SVG 캐릭터·일러스트 **대량 생성**
2. emoji를 다른 임시 아이콘으로 바꿔 **완료 처리**
3. 서로 다른 스타일의 이미지 **혼합 적용**
4. 기존 승인 이미지 **재디자인**
5. placeholder / TEMP를 **REAL로 표시**
6. CSS만으로 고급 일러스트처럼 **위장**
7. AI 생성 이미지가 기존 톤과 달라도 **그대로 production 등록**

## 허용 (동결 중)

- **기능 개발** (게임 로직, UX, Learning, 저장 등)
- Visual Registry **구조·슬롯·키 유지** (스키마 보존)
- 이미지가 없는 곳을 **TEMP / FALLBACK** 으로 명확히 유지
- 승인된 파일이 전달된 경우에만:
  - `public/assets/suksuk/...` 슬롯에 배치
  - Registry에서 해당 키만 `TEMP → REAL` 승격
  - 문서/매니페스트 갱신

## 현재 정책과의 관계

- `docs/ILLUSTRATION_PACK_V3.md` 슬롯 규약 유지
- `src/design/visualAssets.ts` Registry V3 유지
- 기존 승인 자동차·보상 WebP (`/assets/chars/...`) REAL 유지·미변경
- TEMP SVG는 “에셋이 있다”는 뜻이 아니라 **교체 대기 슬롯**

## 완료 판정 금지

TEMP 슬롯 개수, SVG 존재, 빌드 성공만으로  
그래픽 작업을 **완료**라고 보고하지 않는다.

실제 그래픽 완료 = **별도 승인된 파일이 production REAL로 등록된 상태**만 해당한다.
