## 1. 상용화 최소 기준 (Ssuk Complete Bar)

앞으로 게임을 “완성”이라 부르려면 **전부 충족**:

1. 아이가 **직접 조작**한다 (애니메이션 시청만 금지).
2. 행동에 **의미 있는 피드백**이 있다 (색/소리/모션이 원인-결과로 연결).
3. **한 번 터치로 끝나지 않는다** (라운드·세션·창작 과정 존재).
4. **여러 콘텐츠/문제 조합**이 있다 (콘텐츠 ≥ 실질적 다양성 기준, 아래 참고).
5. 반복 시 **변화**가 있다 (셔플만으로 부족할 때는 난이도·맵·스토리 변화).
6. **연령/난이도 변화**가 있다 (최소 2단계).
7. **시각 완성도**가 PLACEHOLDER/POOR가 주력이 아니다.
8. 필요한 경우 **음성 안내**가 있다 (플래그십은 녹음 또는 큐레이션 TTS).
9. **모바일 터치 UX**가 좋다 (큰 타깃, 드래그 필요 시 드래그, 툴바 과점유 금지).
10. **Learning Core와 자연스럽게** 연결된다 (억지 성공/실패 금지; 창작은 engaged/completed).

**콘텐츠 양 하한 (참고):** 퀴즈류 문제군 ≥15 변형, 맵/퍼즐 ≥8, 스토리 ≥5편, 색칠 도안 ≥30, 기억 ≥3 보드 크기, 리듬 ≥8 패턴 + 타이밍 판정.

## 10. 게임별 구체 개선안 (발췌 · 전체는 표의 판정과 결합)

### REBUILD 우선
- **톡톡 리듬:** 타이밍 윈도우·실패·쉼표 준수. 현재는 N연타=성공 → **사기 리듬**.
- **모양 찾기:** `choices`에 target 미포함 가능. 라벨/고유색 치트 제거.
- **미로 운전:** 폴리라인→격자 미로+벽+막다른 길.
- **자동차 만들기:** 자유 파츠 조립 or “맞춰요”로 정직 리네임.
- **색깔 섞기:** 자유 혼합, 결과 스포일러 제거.
- **세차 / 모래:** 제스처·레이어 기반 sensory로 재설계.
- **동화:** 다권 스토리팩+장면 일러스트+읽기 가이드.

### MERGE/REPLACE
- **색 계열 통합:** 풍선+색찾기+레이스+색깔퀴즈 → Progressive Color Search 1개.
- **정렬 통합:** 차고+주차+줄세우기 → Color Sort 1개(난이도 래더).
- **신호 통합:** WaitGo+TrafficLight → Impulse/Safety 1개.
- **사운드 통합:** SoundBoard+CarSounds → 실음원 청취/퀴즈.
- **그림 통합:** FingerPaint → Color Studio free.
- **스티커:** 게임 타일 제거, 보상 허브로 이동.

### UPGRADE
- **색칠 스튜디오:** 도안 품질·수량, 채움 진행 축하, REAL 라인아트.
- **따라하기 / 퍼즐 / 메모리 / 스탬프 / 숨은그림 / 버스세기:** 콘텐츠 래더+터치 제스처+아트.
