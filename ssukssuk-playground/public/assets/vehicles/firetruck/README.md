# Firetruck production parts

`REFERENCE IMAGE IS NOT A GAME ASSET.`

This folder documents the workshop firetruck part set. Runtime parts are authored as independent layered SVG components in:

`src/assets/vehicles/firetruck/`

| Part | File / component | Paintable | Notes |
|---|---|---|---|
| body | `FiretruckBody` | yes | Main chassis |
| door | `FiretruckDoor` | yes | Cabin door / side panel |
| window | `FiretruckWindow` | yes | Windshield + eyes |
| bumper | `FiretruckBumper` | yes | Front bumper + lights |
| ladder | `FiretruckLadder` | yes | Roof ladder |
| light | `FiretruckLight` | yes | Siren lamp |
| front-wheel | `FiretruckFrontWheel` | yes | Rotates while driving |
| rear-wheel | `FiretruckRearWheel` | yes | Rotates while driving |
| shadow | `FiretruckShadow` | no | Ground contact |

Do **not** place Visual Bible crops, screenshot slices, or whole-vehicle hue filters here.
