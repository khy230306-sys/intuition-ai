# 잽 — 순발력 모바일 아케이드

탭·스와이프·색 찾기로 반응 속도를 겨루는 모바일 웹 게임입니다.
**한 판 더**가 나오도록 랭크·피버·데일리·니어미스 루프를 넣었습니다.

## 중독 / 승부 루프

| 시스템 | 역할 |
|--------|------|
| **랭크 7단계** | 루키 → 레전드. 판마다 XP, 승급 연출 |
| **피버** | 콤보 5부터 ×1.5. 끊기면 아쉬운 손맛 |
| **스테이지** | 5라운드마다 클리어 보너스 + 목숨 회복, 난이도↑ |
| **S/A/B/C 등급** | 반응 속도 평가. PERFECT 수집욕 |
| **데일리 도전** | 매일 바뀌는 목표 점수 + 클리어 XP |
| **니어미스** | 베스트 120점 이내 실패 시 「복수하기」 CTA |
| **메달 18종** | 콤보·점수·연속일·누적판 수집 |

## 라운드

| 라운드 | 설명 |
|--------|------|
| **GO** | WAIT → 초록불 순간 탭. 성급하면 아웃 |
| **SWIPE** | 화살표 방향 스와이프 |
| **PICK** | 지시 색만 탭. 스테이지↑ 시 색 증가 |

## 실행

```bash
cd zap-arcade
npm install
npm run dev
```
